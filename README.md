# sqmDataCompare (Binaries)

Kompilierte Windows-Binaries (Releases) zu [sqmDataCompare](https://www.powershelldba.de/sqmdatacompare/). Enthält nur Build-Output, keinen Quellcode.

Download, entpacken, `sqmDataCompare.exe` starten. .NET Framework 4.8 (in Windows 10 2004+/Windows 11 enthalten), kein Installer nötig.

Vergleicht die Dateninhalte gleichnamiger Tabellen zweier SQL-Server-Datenbanken (Hash-Buckets, danach Detail nur für abweichende Bereiche), rein lesend, mit HTML-Report. CLI-Hilfe und Verfahren: siehe Projektseite.
